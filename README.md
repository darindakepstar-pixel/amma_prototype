# АММА — прототип сайта

Кликабельный прототип сайта АММА для России: цветочный магазин, малый опт для флористов и крупный опт из Китая. Стиль — жидкое стекло, воздух и парящие товары, по фирменному стилю АММА.

| Страница | Файл |
| --- | --- |
| Главная | `index.html` |
| Цветочный магазин | `shop.html` |
| Карточка букета | `product.html` |
| Малый опт — флористам | `florist.html` |
| Крупный опт — из Китая | `wholesale.html` |

Цены, адреса, сроки и реквизиты в квадратных скобках — заглушки. Букеты и растения нарисованы, на сайте их заменят фото товаров без фона.

Страницы закрыты от поисковиков (`noindex`), но открываются у всех, у кого есть ссылка.
