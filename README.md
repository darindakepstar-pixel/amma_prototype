# Сайт АММА в России — прототип

Кликабельный прототип: магазин, малый и крупный опт, вход, 3D-конструктор букета.
Дизайн и код — Дария Кромберг.

## Страницы
- `index.html` — главная
- `shop.html` — цветочный магазин (11 разделов)
- `product.html` — карточка букета
- `builder.html` — собрать свой букет в 3D
- `florist.html` — малый опт для флористов
- `wholesale.html` — крупный опт из Китая
- `login.html` — вход и регистрация
- `about.html` — о компании, история, теплица (тексты примерные)

## Язык
Кнопка «中文» в шапке переключает весь сайт на китайский, «RU» — обратно.
Выбор запоминается в браузере. Перевод — в `i18n.js`.

## Как выложить
Все файлы — в корень репозитория, без папок. Рядом должен лежать `.nojekyll`.
Страницы закрыты от поисковиков (`noindex`), но открываются по ссылке.
