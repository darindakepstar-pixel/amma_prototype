# АММА — прототип сайта

Кликабельный прототип сайта АММА для России: цветочный магазин, малый опт для флористов, крупный опт из Китая и 3D-конструктор букета. Стиль — жидкое стекло, воздух и парящие товары, по фирменному стилю АММА.

| Страница | Файл |
| --- | --- |
| Главная | `index.html` |
| Цветочный магазин (11 разделов) | `shop.html` |
| Карточка букета | `product.html` |
| 3D-конструктор «Собрать свой букет» | `builder.html` |
| Вход и регистрация | `login.html` |
| Малый опт — флористам | `florist.html` |
| Крупный опт — из Китая | `wholesale.html` |

3D-конструктор работает на three.js 0.160 (`three.module.min.js`, `OrbitControls.js` лежат рядом — внешние серверы не нужны). Открывайте сайт через GitHub Pages, а не двойным кликом по файлу: браузер не загрузит 3D с диска.

Цены, адреса, сроки и реквизиты в квадратных скобках — заглушки. Букеты на витрине нарисованы, на сайте их заменят фото товаров без фона.

Страницы закрыты от поисковиков (`noindex`), но открываются у всех, у кого есть ссылка.
